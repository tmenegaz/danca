## Como usar em aula

1. Abra `index.html` no navegador e navegue até a aula do dia.
2. Para projetar ou imprimir sem depender do navegador, use `ciclo-01-batata-sala-rosa.pdf`.
3. Para editar: altere os Markdown em `professores/dedao-aberto/ciclos/` e rode

   ```bash
   tools/gerar-ciclo.sh dedao-aberto 01 batata-sala-rosa
   node tools/check-pacote.js professores/dedao-aberto/ciclos/ciclo-01-batata-sala-rosa
   ```
