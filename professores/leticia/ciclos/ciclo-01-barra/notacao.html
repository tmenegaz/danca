Aviso de proveniência (leia antes de usar)

Este documento não é uma transcrição do sistema Benesh. É um código do ciclo: um conjunto pequeno de sinais, baseado em conceitos do sistema, com o qual os exercícios deste ciclo podem ser lidos de volta sem depender da memória de quem deu a aula.

Nota (P-15). Um ciclo que registra exercícios em notação declara o código usado. Este código é do ciclo — os sinais valem para os exercícios registrados aqui, e um sinal novo exige uma linha nova no Glossário do código Benesh.
