## Como usar em aula

1. Abra `index.html` no navegador e navegue até a aula do dia.
2. Para projetar ou imprimir sem depender do navegador, use `ciclo-01-barra.pdf`.
3. Para editar: altere os Markdown em `professores/leticia/ciclos/` e rode

   ```bash
   tools/gerar-ciclo.sh leticia 01 barra
   node tools/check-pacote.js professores/leticia/ciclos/ciclo-01-barra
   ```
