## Como usar em aula

1. Abra `index.html` no navegador e navegue até a aula do dia.
2. Para projetar ou imprimir sem depender do navegador, use `ciclo-01-calango-rosa.pdf`.
3. Para editar: altere os Markdown em `professores/pe-torto/ciclos/` e rode

   ```bash
   tools/gerar-ciclo.sh pe-torto 01 calango-rosa
   node tools/check-pacote.js professores/pe-torto/ciclos/ciclo-01-calango-rosa
   ```
