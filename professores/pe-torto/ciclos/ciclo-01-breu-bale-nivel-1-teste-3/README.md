2. Para projetar ou imprimir sem depender do navegador, use `ciclo-01-breu-bale-nivel-1-teste-3.pdf`.
3. Para editar: altere os Markdown em `professores/pe-torto/ciclos/` e rode

   ```bash
   tools/gerar-ciclo.sh pe-torto 01 breu-bale-nivel-1-teste-3
   node tools/check-pacote.js professores/pe-torto/ciclos/ciclo-01-breu-bale-nivel-1-teste-3
   ```
