## Como usar em aula

1. Abra `index.html` no navegador e navegue até a aula do dia.
2. Para projetar ou imprimir sem depender do navegador, use `ciclo-01-maria.pdf`.
3. Para editar: altere os Markdown em `professores/tiago/ciclos/` e rode

   ```bash
   tools/gerar-ciclo.sh tiago 01 maria
   node tools/check-pacote.js professores/tiago/ciclos/ciclo-01-maria
   ```
