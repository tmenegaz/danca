# Relatórios

Relatórios **pós-aula** deste professor, um por aula, em
`relatorios/ciclo-<XX>/aula-<NN>-<escola>.md`.

O guia do que observar é **gerado** pelo pacote do ciclo — a página
`ciclos/ciclo-XX-<escola>/guia-de-observacao-<NN>.html`, escrita a partir do PO e do
plano (peça 3 da migração; ver `ARQUITETURA-CAPTURA.md` §8) — e o
que se marcou durante a aula vem da folha de captura
(`ciclos/ciclo-XX-captura-aula-<NN>.md`). O relatório é escrito **depois** da aula,
com as marcas da folha como âncora de memória: o que se registra é o que aconteceu,
sem classificar (P-06). As alunas são referidas pelos apelidos declarados no PO
(P-12).
