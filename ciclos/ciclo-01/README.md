## Como usar em aula

1. Abra `index.html` no navegador e navegue até a aula do dia.
2. Para projetar ou imprimir sem depender do navegador, use `ciclo-01.pdf`.
3. Para editar: altere os Markdown em `ciclos/` e rode

   ```bash
   tools/gerar-ciclo.sh 01
   node tools/check-pacote.js ciclos/ciclo-01
   ```
